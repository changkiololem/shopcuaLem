Bước 1: Tạo Google Sheet

Tạo Google Sheet mới tại sheets.google.com

Bước 2: Thêm Google Apps Script

  • Vào Extensions → Apps Script
  • Dán code từ file google-apps-script.js
  • Chạy hàm setupSheets() để tạo cấu trúc

Bước 3: Deploy Web App

  • Nhấn Deploy → New deployment
  • Chọn Web app
  • Who has access: Anyone
  • Copy URL sau khi deploy

Bước 4: Cập nhật URL

Mở file HTML này, tìm dòng const SCRIPT_URL = 'https://script.google.com/macros/s/AKfycbzM3NQ9fuM-2O0vwfXpJI7ukh_cjyvdxewveTCGSgIlEyjDx2YaTPZMkGVYcb8VGqw/exec'; và thay bằng URL đã copy.
